Commands
▶ Playback
/playStart playback or play a library sound
/pausePause the current track
/resumeResume playback
/stopStop without clearing the queue
/skipSkip to next track
/previousGo back one track
/volume 0–120Adjust volume
/speed 50–200Change playback speed
⏩ Navigation
/forward <sec>Skip forward N seconds
/backward <sec>Skip backward N seconds
/seek <h> <m> <s>Jump to exact timestamp
/loop [times]Loop current track
📋 Queue
/queueView all queued tracks
/playingShow current track + progress
/shuffleShuffle the upcoming tracks
/seekqueue <pos>Jump to a specific queue position
/remove <pos>Remove a track from queue
/clearClear entire queue
/disconnectLeave voice and clear queue
📚 Sound Library
/upload <name>Save a sound permanently
/libraryView all saved sounds + usage
/play <name>Play a saved sound
/remove_sound <name>Delete from library
🔧 Server Settings
/autoplayAuto-play when files are added
/autodisconnectLeave when queue ends
/blacklistBlock/unblock a user
/role_configRestrict bot to specific roles
/healthView bot status
🎛

Prefer buttons over commands? The Player Hub puts pause, skip, shuffle, and track controls right under the now-playing message — no slash commands needed once music is going.

FAQ
Make sure you're using slash commands (start typing / to see them). If commands don't appear, try kicking and re-inviting the bot — this re-syncs the command list with your server.
You need to be in a voice channel first. The bot also needs "Connect" and "Speak" permissions for that channel. Check your server's role settings.
SporkMP3 supports MP3, WAV, OGG, FLAC, M4A, AAC, MP4, and WEBM. Make sure your file is one of these formats. If your queue is full, remove some tracks or use /clear first.
This is usually a network issue on the server hosting the bot or Discord's voice servers. Try disconnecting and reconnecting. If it persists, it may be temporary Discord infrastructure issues.
If auto-disconnect is enabled, the bot leaves when the queue ends. It also disconnects after being alone in a voice channel for 5 minutes, or after 3 hours of inactivity. Use /autodisconnect false to disable the empty-queue behavior.
